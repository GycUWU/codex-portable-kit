本仓库是现有安装副本的迁移快照。各 skill 保留原 LICENSE、NOTICE、字体许可证与文件内的版权标记；根目录不授予覆盖第三方文件的统一许可证。manifest.json 记录 skill 原目录、已识别的许可证元数据、插件市场与 npm 包来源。

- onetake：feitangyuan/onetake，PolyForm Noncommercial 1.0.0。
- motion-web：保留该安装副本的 LICENSE，按其原有用途限制使用。
- humanizer：blader/humanizer；humanizer-zh：op7418/Humanizer-zh 的中文版本及本机修订，保留对应 LICENSE。
- ai-product-video：dlazy-ai/ai-product-video；smart-charts：hherosoul/dsh-smart-charts。
- Ponytail：DietrichGebert/ponytail，MIT；i-have-adhd：ayghri/i-have-adhd，MIT。
