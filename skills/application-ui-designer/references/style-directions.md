# Application Visual Directions

## Minimal Utility
Restrained palette, compact controls, high clarity, sparse decoration. Good for tools, note apps, converters, developer utilities.

## Editorial
Strong typography, asymmetric composition, content-led rhythm. Good for reading, publishing, knowledge products.

## Warm Consumer
Softer forms, friendly color, approachable typography, supportive empty states. Good for personal apps.

## Creative Studio
Workspace-first, neutral/dark canvas, tool rails, inspectors, command/search affordances. Good for image/PDF/video/drawing software.

## Premium Monochrome
Limited color, precise spacing, restrained motion, strong content/material presentation.

## Playful
Expressive color, custom illustration/icon language, bolder shapes and lively motion. Use only when product personality supports it.
