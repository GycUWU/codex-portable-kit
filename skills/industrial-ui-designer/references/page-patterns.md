# Industrial Page Patterns

## Robot operation
Global status bar; robot/mode/connection state; main 3D/trajectory/live-value workspace; jog/program controls; alarm strip; contextual tool/user-frame/speed data.

## Parameter configuration
Navigation tree; parameter groups; editable fields with units; validation; apply/revert/defaults; changed-value indicators.

## Diagnostics
System tree; live state table; IO/EtherCAT/drive diagnostics; log timeline; detail inspector.
